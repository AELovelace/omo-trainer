Advanced analytics

Date filters use each record's saved local date. Graphs count recorded activity; missing records do not establish that no events occurred. Current protocol and chart counters use complete saved history. Each graph includes exact data and an SVG download.

What each chart line means

Current labels and notes are saved per participant and row ID. Star totals respect the analysis dates; renaming a row also changes its label on older stars.

Participant snapshots

Current enrollment and chart dates, timezone, probability, refusal count and reveal status.

Underlying records

User management

Manage Little Log access for accounts that have signed in. Disabling access revokes Little Log sessions and blocks new ones. LidollID passwords and access to other apps are managed separately. At least one enabled administrator must remain.

Import & export

Export selected participants

Exports include every current record and the complete potty chart for the selected user or everyone. Analysis date filters do not limit these backups. CSV includes readable record fields and JSON cells for full chart rows and dated stars.

Import records and charts

Choose a Little Log CSV or JSON file (up to 16 MiB). Files without participant IDs require an individual user selection. Existing user IDs are preserved; imports never create login accounts, change roles or delete missing records.

Identical records are skipped. Replacing a chart replaces the complete chart. Old CSV exports without IDs receive repeatable IDs; identical rows in those files collapse into one record.

Administrator activity

Latest 100 access changes and imports. Record contents and credentials are excluded.
