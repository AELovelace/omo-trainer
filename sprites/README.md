# Sticker collection

The 16 numbered PNG images are the active reward collection. `_originals/` contains backup source copies and is excluded from rewards and the public asset allowlist.

Additional PNG, WebP, JPEG and GIF images can be added here, including nested folders. Restart Little Log after changes. Keep published relative filenames stable: they determine sticker IDs and ownership history. Numbered assets appear as Sticker 1, Sticker 2, and so on. Removed assets retire their types without deleting balances.
